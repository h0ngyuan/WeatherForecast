# 地图模块多Agent协作重构检查清单

## 验收标准

### 架构验收
- [ ] 每个Agent是一个独立的CompiledGraph（子图）
- [ ] 父图通过`.addNode("agentName", compiledSubGraph)`方式编排子图
- [ ] 父子图共享状态（OverAllState）
- [ ] 支持并行执行多个子图
- [ ] 子图可独立编译和测试

### 功能验收
- [ ] TrendAgent能正确分析周边城市天气趋势
- [ ] SeasonAgent能正确评估季节性风险
- [ ] ImpactAgent能正确计算灾害影响
- [ ] 仲裁节点能正确处理冲突（一致/2个一致/3个都不同）
- [ ] 响应节点能生成结构化最终报告
- [ ] 评测图能回放历史案例
- [ ] 评测图能执行消融测试
- [ ] 所有API接口能正常调用

### 数据验收
- [ ] AgentReport格式正确

## 最终验收

### 核心指标
- [ ] 地图分析API响应时间 < 5秒
- [ ] 评测回放准确率 > 70%
- [ ] 消融测试能正确识别最关键Agent
- [ ] 仲裁冲突处理成功率 100%

### 毕设要求对照
- [ ] 多Agent体系设计：3个SubAgent + 1个Coordinator
- [ ] 支持联动流程：预警→确认→响应建议
- [ ] 地图展示：提供地图数据接口
- [ ] 分区预警：支持区域分析
- [ ] 处置建议：生成结构化建议
- [ ] 消息推送：复用现有通知服务
- [ ] 日志审计：记录Agent执行日志
- [ ] 风险等级判定规则与可解释性：仲裁理由可解释
- [ ] 多Agent通信与冲突消解：共享状态+仲裁机制
- [ ] 应急建议的可执行性与安全边界控制：基于规则的建议

### Harness思想体现
- [ ] 父图控制流程（Coordinator）
- [ ] 子图执行任务（3个Agent）
- [ ] 支持动态编排（可加/减/替换子图）
- [ ] 状态共享或隔离（共享OverAllState）
- [ ] 组件复用（子图可在多个父图中使用）
