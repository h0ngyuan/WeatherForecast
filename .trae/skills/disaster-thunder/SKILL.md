# 雷电灾害风险评估 Skill

## 天气码说明（最美天气自定义代码 - wid）
- 15: 雷阵雨（强对流，有雷电）

## 触发条件
当天气码值在以下范围时触发：
- 15 = 雷阵雨

## 判定规则

### 输入参数
- `weatherCode`: 天气码值（15）
- `durationHours`: 持续小时数（可选）

### 判定逻辑
```
IF weatherCode == 15:
    → 固定 2级（中等）
```

**注意**：雷电灾害**固定为2级**，不因码值或持续时间变化。原因是雷电具有突发性和高危险性，任何程度的雷电都存在触电和雷击风险。

### 等级定义

#### 2级 - 中等（影响特定活动）
**触发条件**：
- 码值 = 15（雷阵雨）

**风险描述**：
雷电天气，户外活动有触电和雷击风险。雷电具有突发性和不可预测性，任何程度的雷电都可能造成人员伤亡。

**建议措施**：
- 避免在空旷地带活动
- 避免在高处、树下、水边停留
- 不要使用金属柄雨伞
- 关闭家用电器电源
- 寻找室内躲避

## 输出格式
```json
{
  "level": 2,
  "type": "雷阵雨",
  "explanation": "详细的风险描述和建议措施"
}
```

## 示例

### 示例1：雷阵雨
```
输入: weatherCode=15, durationHours=2
输出: {
  "level": 2,
  "type": "雷阵雨",
  "explanation": "雷阵雨天气，有雷电风险。建议：避免在空旷地带活动，不要在高处、树下、水边停留，不要使用金属柄雨伞，寻找室内躲避"
}
```

## 特殊说明

### 为什么固定为2级？
雷电具有以下特点：
1. **突发性**：雷电可能在任何时刻发生，难以预测
2. **高危险性**：雷击可造成人员伤亡和财产损失
3. **不可控性**：无法通过防护措施完全避免风险

因此，只要有雷电现象，就固定判定为2级（中等风险），提醒用户注意防范。
