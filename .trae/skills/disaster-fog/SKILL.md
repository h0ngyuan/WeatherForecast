# 大雾灾害风险评估 Skill

## 天气码说明（最美天气自定义代码 - wid）
- 33: 雾/轻雾（能见度<10km）
- 75: 霾/沙尘（空气质量差）

## 触发条件
当天气码值在以下范围时触发：
- 33 = 雾/轻雾
- 75 = 霾/沙尘

## 判定规则

### 输入参数
- `weatherCode`: 天气码值（33或75）
- `durationHours`: 持续小时数

### 判定逻辑
```
IF weatherCode == 33 AND durationHours >= 6:
    → 2级（中等）
ELSE IF weatherCode == 75:
    → 2级（中等）
ELSE:
    → 3级（轻微）
```

**注意**：大雾**不设1级**，因为大雾主要影响交通安全，不会像暴雨、冰雹那样造成直接的人身威胁。

### 等级定义

#### 2级 - 中等（影响特定活动）
**触发条件**：
- 码值 = 33（雾/轻雾）且持续时间 ≥ 6小时
- 或码值 = 75（霾/沙尘）

**风险描述**：
长时间大雾严重影响交通安全，能见度低，易引发交通事故。同时雾霾天气对呼吸系统健康有影响。

**建议措施**：
- 驾车开启雾灯和危险报警闪光灯
- 减速慢行，保持车距
- 避免超车
- 减少户外活动
- 佩戴口罩（雾霾天气）

#### 3级 - 轻微（一般提醒）
**触发条件**：
- 码值 = 33（雾/轻雾）且持续时间 < 6小时

**风险描述**：
短时大雾，注意交通安全即可

**建议措施**：
- 驾车减速慢行
- 开启雾灯
- 注意路况
- 关注天气变化

## 输出格式
```json
{
  "level": 2|3,
  "type": "大雾/霾/沙尘",
  "explanation": "详细的风险描述和建议措施"
}
```

## 特殊说明

### 为什么不设1级？
大雾主要影响：
1. 交通安全（可通过减速等措施降低风险）
2. 呼吸系统（可通过减少外出、佩戴口罩防护）

不像暴雨、冰雹那样会造成直接的人身伤害或财产损失，因此最高设为2级。
