# 降雪灾害风险评估 Skill

## 触发条件
当天气码值在以下范围时触发：
- 60-63 = 小雪、中雪、大雪
- 64+ = 暴雪、强降雪

## 判定规则

### 输入参数
- `weatherCode`: 天气码值 (60+)
- `durationHours`: 持续小时数

### 判定逻辑
```
IF weatherCode >= 64 OR durationHours >= 6:
    → 1级（严重）
ELSE IF durationHours >= 3:
    → 2级（中等）
ELSE:
    → 3级（轻微）
```

### 等级定义

#### 1级 - 严重（全员预警）
**触发条件**：
- 码值 ≥ 64（暴雪/强降雪）
- 或持续时间 ≥ 6小时

**风险描述**：
强降雪可能导致：
- 交通中断
- 道路积雪结冰
- 设施损坏
- 树木倒伏
- 供暖压力增大

**建议措施**：
- 减少不必要外出
- 做好防寒保暖
- 储备生活物资
- 关注交通信息
- 防范管道冻裂

#### 2级 - 中等（影响特定活动）
**触发条件**：
- 码值 60-63（一般降雪）
- 或持续时间 3-6小时

**风险描述**：
降雪天气，道路湿滑，出行需注意安全

**建议措施**：
- 驾车安装防滑链
- 减速慢行
- 步行注意防滑
- 做好防寒措施

#### 3级 - 轻微（一般提醒）
**触发条件**：
- 持续时间 < 3小时
- 且码值 < 64

**风险描述**：
短时降雪，一般性提醒即可

**建议措施**：
- 注意保暖
- 出行注意路面情况
- 关注天气变化

## 输出格式
```json
{
  "level": 1|2|3,
  "type": "降雪",
  "explanation": "详细的风险描述和建议措施"
}
```

## 示例

### 示例1：暴雪持续8小时
```
输入: weatherCode=64, durationHours=8
输出: {
  "level": 1,
  "type": "暴雪",
  "explanation": "强降雪可能导致交通中断、设施损坏、树木倒伏，需做好应急准备。建议：减少不必要外出，做好防寒保暖，储备生活物资，关注交通信息"
}
```

### 示例2：大雪持续4小时
```
输入: weatherCode=63, durationHours=4
输出: {
  "level": 2,
  "type": "大雪",
  "explanation": "降雪天气，道路湿滑，出行需注意安全。建议：驾车安装防滑链，减速慢行，步行注意防滑"
}
```
