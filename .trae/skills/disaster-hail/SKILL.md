# 冰雹灾害风险评估 Skill

## 触发条件
当天气码值在以下范围时触发：
-  hail = 冰雹
- 任何冰雹天气现象

## 判定规则

### 输入参数
- `weatherCode`: 天气码值（冰雹相关）
- `durationHours`: 持续小时数（可选）

### 判定逻辑
```
IF 天气现象包含冰雹:
    → 固定 1级（严重）
```

**注意**：冰雹灾害**固定为1级**，不因码值大小或持续时间变化。原因是冰雹具有直接的物理伤害性，任何程度的冰雹都可能造成人员伤亡和财产损失。

### 等级定义

#### 1级 - 严重（全员预警）
**触发条件**：
- 任何冰雹天气

**风险描述**：
冰雹天气对人身安全、车辆、农作物等有直接威胁。冰雹下落速度快，即使是小冰雹也可能造成伤害，大冰雹可致命。

**建议措施**：
- 立即寻找室内躲避
- 远离窗户（冰雹可能击碎玻璃）
- 车辆驶入地下车库或遮蔽处
- 户外人员用物品保护头部
- 停止一切户外活动

## 输出格式
```json
{
  "level": 1,
  "type": "冰雹",
  "explanation": "详细的风险描述和建议措施"
}
```

## 示例

### 示例1：冰雹
```
输入: weatherCode=hail, durationHours=0.5
输出: {
  "level": 1,
  "type": "冰雹",
  "explanation": "冰雹天气对人身安全、车辆、农作物等有直接威胁，需紧急避险。建议：立即寻找室内躲避，远离窗户，车辆驶入地下车库或遮蔽处，户外人员用物品保护头部"
}
```

## 特殊说明

### 为什么固定1级？
冰雹具有直接的物理伤害性，不存在"轻微冰雹"的概念。即使是小冰雹也可能造成：
- 人员头部受伤
- 车辆玻璃损坏
- 农作物损失

因此冰雹必须按最高级别（1级）处理，确保全员得到预警并采取避险措施。

### 与雷电的区别
- 雷电：2级（有躲避空间）
- 冰雹：1级（直接物理伤害，必须立即避险）
