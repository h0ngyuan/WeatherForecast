# 极端温度灾害风险评估 Skill

## 触发条件
当天气码值在以下范围时触发：
- 高温相关：炎热、高温
- 低温相关：寒潮、低温、寒冷

## 判定规则

### 输入参数
- `weatherCode`: 天气码值（温度相关）
- `durationHours`: 持续小时数（可选）

### 判定逻辑
```
IF 天气现象包含高温/炎热/低温/寒潮:
    → 固定 2级（中等）
```

**注意**：极端温度**固定为2级**，不因温度高低或持续时间变化。

### 等级定义

#### 2级 - 中等（影响特定活动）
**触发条件**：
- 任何极端温度天气（高温或低温）

##### 高温/炎热
**风险描述**：
高温天气，易引发中暑和热射病，对老人、儿童、户外工作者影响较大。

**建议措施**：
- 避免长时间户外活动
- 多补充水分
- 做好防暑降温
- 关注老人儿童健康
- 避免在高温时段外出

##### 低温/寒潮
**风险描述**：
低温寒潮天气，易造成冻伤、呼吸道疾病，对供暖系统、水管等有影响。

**建议措施**：
- 增添衣物保暖
- 注意取暖安全
- 防范管道冻裂
- 关注心脑血管健康
- 减少不必要外出

## 输出格式
```json
{
  "level": 2,
  "type": "高温|低温",
  "explanation": "详细的风险描述和建议措施"
}
```

## 示例

### 示例1：高温
```
输入: weatherCode=heat, durationHours=8
输出: {
  "level": 2,
  "type": "高温",
  "explanation": "高温天气，易引发中暑和热射病。建议：避免长时间户外活动，多补充水分，做好防暑降温，关注老人儿童健康"
}
```

### 示例2：寒潮
```
输入: weatherCode=cold_wave, durationHours=12
输出: {
  "level": 2,
  "type": "寒潮",
  "explanation": "低温寒潮天气，注意防寒保暖。建议：增添衣物，注意取暖安全，防范管道冻裂，关注心脑血管健康"
}
```

## 特殊说明

### 为什么固定2级？
极端温度影响特点：
1. **可预防性**：通过增减衣物、调整作息可有效防护
2. **渐进性**：不会突然造成严重后果
3. **人群差异性**：主要影响特定人群（老人、儿童、病患者）

不像暴雨、冰雹那样具有突发性和直接伤害性，因此设为2级（影响特定活动/人群）。

### 高温 vs 低温
两者风险等级相同（都是2级），但影响不同：
- **高温**：中暑、热射病、户外作业风险
- **低温**：冻伤、呼吸道疾病、供暖压力
