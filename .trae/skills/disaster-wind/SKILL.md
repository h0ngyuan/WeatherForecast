# 大风灾害风险评估 Skill

## 触发条件
当天气码值在以下范围时触发：
- 70 = 大风
- 71+ = 强风/狂风

## 判定规则

### 输入参数
- `weatherCode`: 天气码值 (70+)
- `durationHours`: 持续小时数

### 判定逻辑
```
IF weatherCode >= 70 OR durationHours >= 6:
    → 1级（严重）
ELSE IF durationHours >= 3:
    → 2级（中等）
ELSE:
    → 3级（轻微）
```

### 等级定义

#### 1级 - 严重（全员预警）
**触发条件**：
- 码值 ≥ 70（大风/强风）
- 或持续时间 ≥ 6小时

**风险描述**：
大风天气持续时间长或风力强，可能造成：
- 高空坠物
- 树木倒伏
- 广告牌脱落
- 设施损坏

**建议措施**：
- 避免在高大建筑物、广告牌、树下停留
- 关好门窗
- 固定室外物品
- 停止高空作业

#### 2级 - 中等（影响特定活动）
**触发条件**：
- 持续时间 3-6小时

**风险描述**：
风力较大，影响户外作业和高空活动

**建议措施**：
- 停止高空作业
- 避免在空旷地带活动
- 注意防风
- 妥善安置易被风吹动的物品

#### 3级 - 轻微（一般提醒）
**触发条件**：
- 持续时间 < 3小时

**风险描述**：
短时大风，一般性提醒即可

**建议措施**：
- 注意防风
- 妥善安置易被风吹动的物品
- 关注天气变化

## 输出格式
```json
{
  "level": 1|2|3,
  "type": "大风",
  "explanation": "详细的风险描述和建议措施"
}
```

## 示例

### 示例1：强风持续8小时
```
输入: weatherCode=71, durationHours=8
输出: {
  "level": 1,
  "type": "强风",
  "explanation": "大风天气持续时间长或风力强，可能造成高空坠物、树木倒伏、广告牌脱落等危险，需全员注意防范。建议：避免在高大建筑物、广告牌、树下停留，关好门窗，固定室外物品"
}
```
